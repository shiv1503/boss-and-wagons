# Boss and Wagons

Website for **Boss and Wagons: Ceramic & PPF Experts**.

Built with React, TypeScript, Vite, Tailwind CSS and Framer Motion.

## Brand

- Colours: black `#050507` and yellow `#F3C30D` (Tailwind tokens: `baw-yellow`, `baw-yellow-light`, `baw-yellow-dark`)
- Logo: `src/assets/logo-baw.png` (site use) and `public/logo-baw-hires.png` (full 3134px master)

## Content

All editable copy (brand name, contact details, services, packages) lives in `src/data/content.ts`.
Contact details are still placeholders. Replace them before launch.

## Scripts

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check + production build
npm run lint
```
